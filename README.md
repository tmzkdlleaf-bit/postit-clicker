# 포스트잇 클리커

바탕화면에 떠 있는 캐릭터 + 할 일 포스트잇 프로그램.

## 실행

```
npm install
npm start
```

exe 설치 파일: `npm run build:win` → `dist` 폴더

## 쓰는 법

| 하는 것 | 일어나는 일 |
|---|---|
| 캐릭터 누르기 | 꾹 눌리고 소리 + 대사 |
| 캐릭터 두 번 누르기 | 포스트잇 판 열기 |
| 캐릭터 우클릭 | 할 일 목록 |
| 캐릭터 끌기 | 위치 옮기기 |
| 단축키 (기본 Ctrl+Alt+Space) | 할 일 목록 열기·닫기 |

할 일 목록에서:
- 「과제 내일까지」「금요일 3시 회의」「10/30 보고서」「3일 후 택배」처럼 적으면 마감이 자동으로 잡혀요
- 체크한 직후 「되돌리기」, 아래 「오늘 끝낸 일」에서 다시 풀 수도 있어요
- 할 일을 누르면 판이 열리면서 그 포스트잇으로 이동
| 작업표시줄 오른쪽 아이콘 | 목록, 판, 캐릭터 보이기·숨기기, 설정, 종료 |

판에서:
- 판 이름 옆 `⋯` (또는 판 이름 두 번 누르기): 이름, 종류, 배경, 삭제
- 체크 줄 옆 `마감`: 마감 날짜·시간, 알림, 중요도
- 포스트잇을 누르면 위에 도구: 색, 줄 추가, 테이프·핀, 기울기, 다른 판으로 옮기기, 삭제 (삭제는 되돌리기 가능)
- Ctrl+휠 또는 왼쪽 아래 버튼으로 확대·축소, Ctrl+N 새 포스트잇

## 설정에서 바꿀 수 있는 것

- 캐릭터: 여러 개 추가, 그림(조각 3장 또는 GIF 3개), 크기·눌림, 소리(기본·내 파일·끔), 말풍선(모양·색·글꼴·크기), 상황별 대사, 내보내기·가져오기(.pchar)
- 포스트잇: 색 목록, 글꼴(내 컴퓨터 글꼴 포함)
- 우선도: 판 종류와 중요도, 날짜를 우선하기 시작하는 날, 올리고 내리는 단어
- 일반: 밝게·어둡게, 목록 단축키, 자동 실행

대사에 쓸 수 있는 칸: `{할일}` `{마감}` `{판}` (마감 임박), `{개수}` (아침 인사)

## 동기화 (컴퓨터 ↔ 탭)

설정 → 동기화에서 이메일로 로그인하면 판, 포스트잇, 포스트잇 색·글꼴·우선도 설정이 Supabase(캘린더 프로젝트 안 `postit_` 표)로 맞춰져요. 다른 기기에서 바꾸면 바로 반영되고, 같은 포스트잇을 양쪽에서 고치면 나중에 고친 쪽이 남아요. 캐릭터는 기기마다 따로이고, 옮길 땐 설정 → 캐릭터 → 내보내기·가져오기(.pchar)를 써요.

Supabase 표 만들기: `supabase/postit-setup.sql` (이미 실행해 둠, 다시 실행해도 안전)

## 새 버전 내보내기 (자동 업데이트)

```
npm run release
```

버전 끝자리가 하나 올라가고(0.3.0 → 0.3.1) 바뀐 내용과 함께 GitHub에 올라가요. GitHub가 몇 분 안에 설치 파일을 만들어 릴리스에 올리고, 설치해 둔 프로그램은 켜질 때(그리고 6시간마다) 새 버전을 찾아서 받을지 물어봐요.

- 기능을 크게 바꿨을 때: `npm run release:minor` (0.3.1 → 0.4.0)
- 진행 상황: 저장소의 Actions 탭

## 저장 위치

`%APPDATA%\postit-clicker\postit-data.json`, 그림·소리는 같은 폴더의 `assets`, 날마다 자동 백업은 `backups` (14일치)
